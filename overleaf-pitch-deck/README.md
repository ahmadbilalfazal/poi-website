# Proof Investor Deck (Overleaf)

This folder contains a self-contained 10-slide Beamer deck. It uses TikZ for the diagrams, so it has no image files or external asset dependencies.

## Compile in Overleaf

1. Create a blank Overleaf project.
2. Upload `main.tex` from this folder.
3. Set the compiler to pdfLaTeX and compile.

The existing `pitchdeck.pdf` in the website folder is unchanged.

## Before sharing with investors

The deck deliberately avoids claims that are not substantiated in the current product repository. Confirm and add, if available:

- Current raise target, instrument, and runway assumptions.
- Founder biography and relevant operating experience.
- Verified design partners, pilots, customers, or revenue, with dates and definitions.
- A sourced market-sizing estimate and the exact initial customer segment.
- A direct founder email or preferred demo-request link.

Sample product and report content is labeled as illustrative/demo data. The business model and network effect are described as hypotheses, not established traction.
