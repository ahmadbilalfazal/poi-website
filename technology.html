The product

Evidence that travels with the work.

Proof connects collaborative sessions to professional profiles and hiring workflows, giving people more context than a resume or a one-off interview can provide.

Product loop

One connected workflow, from room to reputation.

01

Collaborative rooms

People work together in configurable sessions for software engineering, data analysis, design reviews, business cases, research, and other structured work. Room tools include video, chat, notes, whiteboards, and code.

02

Session evidence

Room activity is recorded as ordered events. After a session, an analysis worker produces a report with observed strengths, improvement areas, suggestions, and performance metrics; AI analysis can fall back to deterministic evidence scoring.

03

Professional profiles

Profiles combine experience, education, projects, skills, credentials, completed session reports, and performance history. People can build a more inspectable record of their work over time.

04

Team discovery

Hiring teams can search profiles, review work history, compare candidates, publish jobs, manage applications, and invite candidates to structured Proof Sessions.

System architecture

A full-stack application built around a shared evidence model.

The source release includes the web application, real-time API, asynchronous analysis, data services, and a code-execution service. The components are designed to run together as a local Docker Compose environment.

Where the product stands

The repository provides a runnable local release. It does not claim production-scale operation: public deployment still requires managed infrastructure, production media routing, hardened execution, billing and email integrations, security and compliance review, and load testing.
